## Learnings / gotchas
- http MockClient handlers must actually call `api.request` in sync-engine tests —
  stub handlers that return directly bypass the network path and hide failures.
- EscPosBuilder latin1 output: map ₹→"Rs." at the byte-builder edge (thermal codepages).
- Flutter web can't open raw TCP — conditional import (`dart.library.io`) keeps the
  same `PrinterAdapter` API with a no-op fallback.
- `data:` SSE frames split on `\n\n`; keep a StringBuffer across chunk boundaries.
- Provider methods stay sync; `_sync.push` is fire-and-forget with ack callbacks —
  no screen was rewritten (D-003 held), which kept the 8 existing widget tests green.

## Known limitations (documented, not silent)
- Offline PIN verification falls back to the seeded demo staff only (no client PIN
  vault in v1) — Q-2 updated.
- SSE hub drops events for slow consumers; terminals self-heal via hydrate on
  reconnect (Q-5 open).
- Waiter assignment by name has no server path (backend keys waiters by id);
  order-level waiter is set at create from the JWT, table waiter stays local-only.
