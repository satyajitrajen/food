## Learnings (→ PROJECT_STATE gotchas)
- chi middleware vs internal middleware import collision — alias `chimw`.
- SQLite scans: store times as TEXT, scan into strings then `ParseTime`.
- Generate row IDs server-side when inserting via multiple code paths (`AddOrderItem`).
- One clamping authority: `service.ApplyBilling`; endpoints never re-derive money.
